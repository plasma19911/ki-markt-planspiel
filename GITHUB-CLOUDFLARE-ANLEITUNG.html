KI Markt-Planspiel – GitHub + Cloudflare

1. Top-500-Liste

GitHub → Actions → Refresh Top-500 Universe → Run workflow. Danach enthält public/universe.json die 500 größten gefundenen Aktien nach Marktkapitalisierung. Anschließend aktualisiert GitHub die Liste täglich.

2. Cloudflare verbinden

Cloudflare → Workers & Pages → Create application → Import a repository → GitHub → plasma19911/ki-markt-planspiel.

Production branch: main
Build command: leer
Deploy command: npx wrangler deploy

3. Speicherung

Depot, Positionen und vollständige History liegen in einem SQLite Durable Object. Keine D1-ID und kein Marktdaten-API-Key nötig.

4. Betrieb

Nach dem Deploy die workers.dev-Adresse öffnen, Spielgeld und Laufzeit wählen und Neu starten. Cloudflare scannt danach jede Minute weiter, auch wenn dein PC aus ist.

5. Hinweis

Nur Paper-Trading. Keine echten Orders. Kostenlose Yahoo-Finance-Daten können verzögert oder zeitweise nicht erreichbar sein; Fehler werden in die History geschrieben.
